# Concept: Optical Character Recognition

## Definition

**Optical Character Recognition (OCR)** is a technology that allows computers to read text from images. It works in two steps:

1. **Detection**: First, it finds where text appears in an image
2. **Extraction**: Then, it reads and extracts that text so it can be used digitally

OCR is often paired with analysis tools that can understand what the extracted text means - like reading specific information from forms, receipts, or documents.
